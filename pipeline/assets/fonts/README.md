# Fonts

Self-hosted so no page contacts a font CDN (`pipeline/src/wsc_pipeline/build.py`).
Each file is a Latin subset of an openly licensed family, served from
`/fonts/`. The copyright notice and licence URL also sit in each file's
`name` table (IDs 0 and 14).

| File | Family | Copyright | Licence |
|---|---|---|---|
| `big-shoulders-display-latin.woff2` | Big Shoulders Display 2.002 | 2019 The Big Shoulders Project Authors | SIL OFL 1.1: `OFL-BigShoulders.txt` (upstream copy) |
| `big-shoulders-text-latin.woff2` | Big Shoulders Text 2.002 | 2019 The Big Shoulders Project Authors | SIL OFL 1.1: `OFL-BigShoulders.txt` |
| `public-sans-latin.woff2` | Public Sans 2.001 | 2015 The Public Sans Project Authors | SIL OFL 1.1, GSA modifications CC0: `LICENSE-PublicSans.md` (upstream copy) |

The licence texts are copied verbatim from
https://github.com/xotypeco/big_shoulders/blob/master/OFL.txt and
https://github.com/uswds/public-sans/blob/develop/LICENSE.md (fetched
2026-09-17).
